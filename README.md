# TradeNova — Frontend Prototype

A mobile-first trading education dashboard prototype.

## Included
- Home dashboard
- Trading Academy / courses
- Demo practice screen
- Progress and achievements
- Profile/settings screen
- Responsive mobile bottom navigation
- TradeNova branding and visual system

## Run
Open `index.html` in a browser.

This is a frontend prototype only. Demo trading uses illustrative data and is not connected to a broker, wallet, payments, or real-money trading.
